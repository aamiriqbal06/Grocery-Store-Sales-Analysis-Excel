# 🚀 Project Overview

This project transforms raw supermarket sales data into an interactive and visually appealing **Business Intelligence dashboard** using Microsoft Excel.

The dashboard allows users to quickly understand:

- 💰 Overall Sales
- 💵 Overall Profit
- 🧾 Number of Orders
- 📊 Profit Margin
- 🌎 Regional Performance
- 🛒 Category Performance
- 📈 Sales Comparison
- 🔎 Interactive Filtering

# 🎯 Dashboard Features

### 💰 Sales Analysis

The dashboard provides an overview of total sales and allows sales performance to be compared across different regions.

### 💵 Profit Analysis

Profit performance can be analyzed using KPI cards and category/region comparisons.

### 🌎 Region Analysis

The dashboard contains interactive filtering for:

- 🇮🇳 Central
- 🇮🇳 East
- 🇮🇳 North
- 🇮🇳 South
- 🇮🇳 West

### 🛒 Category Analysis

Sales can be analyzed across:

- 🥖 Bakery
- 🥤 Beverages
- 🥩 Eggs, Meat & Fish
- 🌾 Food Grains
- 🥬 Fruits & Veggies
- 🫙 Oil & Masala
- 🍿 Snacks

### 🔎 Interactive Filters

Users can select:

```text
Region
   ↓
Central
East
North
South
West

```
